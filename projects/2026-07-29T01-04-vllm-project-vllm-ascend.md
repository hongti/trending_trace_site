PR 活动主要围绕**缺陷修复**和**新特性支持**，特别是针对 A3 硬件和 KV Cache 的优化：

**1. 缺陷修复**
*   **移除 memcache 后端不必要的 `lazy_init`**：`lazy_init` 仅在 A3 硬件搭配 mooncake 后端及 deepseekv4 压缩模型时才需要，memcache 后端会根据设备类型内部处理初始化，传入该参数会导致异常。该修复已被批量合入多个版本（`v0.23.0`, `v0.24.0`, `v0.25.1` 及 `main`分支）。（PR #13028, #13029, #13030, #13031）
*   **恢复 v0.23.0 同步 AscendStore 保存**：修复了此前 PR 导致非分层保存变为异步的回归问题，在 `wait_for_save()` 中恢复了 `request_queue.join()` 屏障，确保保存逻辑正确。（PR #13024）

**2. 新特性**
*   **支持稀疏 KV Cache 卸载**：实现了 RFC #48203 中的部分功能，支持分层和稀疏 KV 缓存卸载，旨在支持更长的序列长度。（PR #13026）
*   **MRV2 支持 MTP FullGraph**：在 MRV2（Multi-Step Runner V2）中引入了对 MTP（Multi-Token Prediction）FullGraph 的支持。（PR #13027）
*   **A3 硬件 MegaMoe 支持**：新增了 Mega moe a3 25 模型支持（PR #13025）；同时为 A3 添加了 CANN MegaMoe 融合 MC2 支持，提升通信效率。（PR #13023）

**3. CI/自动化**
*   **自动更新测试时间**：CI 自动化工作流更新了 `test_config.yaml` 中的预估测试时间（`estimated_times`）。（PR #13032）
